# NutriTrack 🥑

NutriTrack is a modern, lightweight, and responsive daily diet and nutrition tracker website built with HTML5, CSS3, and vanilla JavaScript.

## Features

- **Daily Calorie & Macro Tracking**: Real-time progress bars for calories, protein, carbs, and fats against daily targets.
- **Meal Journal**: Log meals categorized by Breakfast, Lunch, Dinner, and Snacks with macro breakdowns.
- **Hydration Tracker**: Interactive 8-glass water counter to stay hydrated throughout the day.
- **Custom Goals**: Set and persist personalized daily calorie targets.
- **Client-Side Storage**: Keeps all your daily entries and targets securely saved in `localStorage`.
- **Clean & Responsive UI**: Designed with clean typography and modern styling that adapts seamlessly to desktop and mobile screens.

## Getting Started

Because NutriTrack is a pure static web application, no build steps or package installations are required!

1. Clone or download this repository:
   ```bash
   git clone https://github.com/binduka41-lang/diet-tracker.git
   ```
2. Open `index.html` directly in any modern web browser, or serve it using any local HTTP server:
   ```bash
   npx serve .
   ```
